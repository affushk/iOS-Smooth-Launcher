# iOS Smooth Launcher

Android ke liye lightweight iOS-inspired HOME launcher.

## Features
- Real Android HOME launcher
- Installed apps grid
- Search bar
- Rounded glass-style dock
- Smooth entry and app-open animations
- Default launcher shortcut
- GitHub Actions APK build

## APK
GitHub me **Actions > Build Android APK** open karke latest successful run se **iOS-Smooth-Launcher-debug** artifact download karein.
